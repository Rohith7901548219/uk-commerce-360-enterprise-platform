# LinkedIn project description

**UK Commerce 360° — independent historical retail intelligence project**

Built an integrated analytics and engineering platform around UCI Online Retail II
(2009–2011), using Python, SQLAlchemy/PostgreSQL, dbt, FastAPI and Streamlit. The local
warehouse preserves 1,067,371 source rows with explicit accepted, quarantined and
duplicate dispositions. Customer outputs use HMAC pseudonyms.

The project combines revenue/returns reporting, RFM segments, monthly customer cohorts,
product associations, chronological repeat-purchase evaluation and rolling-origin
revenue forecasting. An eleven-page application exposes backend computations and
explicitly hypothetical marketing scenarios. Power BI M/DAX/theme assets, Windows
automation, tests and documentation accompany the code.

Kafka-compatible historical replay/DLQ code is implemented; actual Redpanda/Compose
runtime verification remains outstanding. Power BI Desktop authoring and complete
Azure deployment validation are also incomplete. This is coding-agent-assisted
portfolio work, not employment, a commercial deployment or evidence of financial uplift.
